# Ping My Nest (frontend)

Landing page for **Ping My Nest** — USM course seat alerts.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Geist via `next/font`

## Routes

- `/` — marketing landing
- `/search` — stub (accepts `?q=`)
- `/signup` — stub
